# Community rejection cases (2022–2026)

Real rejection stories collected from Apple Developer Forums, Google Play Developer Community, GitHub issues, Hacker News and developer blogs (English, Korean, Japanese, Chinese). Compiled 2026-08-28. Every case links to its source; **high** = the page was read in full, **medium** = search snippet / unresolved thread where the "fix" is expert advice rather than a confirmed approval.

How the skill uses this file:
- **Mode B (rejection intake)** — match the reviewer's wording against the *Reviewer phrasings* index at the bottom to jump to the checklist IDs and to similar cases.
- **Mode A (pre-check)** — when an item is FAIL/WARN, cite the closest case here ("this exact thing got someone rejected — this is what fixed it").
- Contributions: add a bullet in the matching section with the same fields; map it to checklist IDs (`→`).

Not covered (crawler-blocked): Reddit, Stack Overflow, CSDN. Fields: date · app · guideline/policy · reviewer quote · cause · fix · rounds · source (confidence, language) · → checklist IDs.

### 1.2 User-Generated Content
- **2025-11 · messaging/events app (Bitchat-like)** — 1.2. ## Patterns (both stores)

1. **The reviewer can't reach the feature** — broken/expired/2FA demo accounts, forced-update gates, ATT or age gates shown too late, deletion buried. Fixes: demo mode, version-check logic, screenshots/videos in review notes. → ACC-03, CONTENT-11, META-05
2. **Library-injected permissions and capabilities** — `READ_MEDIA_*`, FGS types, `QUERY_ALL_PACKAGES`, `USE_FULL_SCREEN_INTENT`, `AD_ID`; HealthKit/FamilyControls/ATT references left in the binary or on the App ID. Fixes: `tools:node="remove"`, merged-manifest audit, capability removal. → AND-PERM-13, IOS-ENT-04
3. **Stale artifacts in other tracks / App ID** — rejections cite old version codes; capability still enabled in the portal. → AND-CONSOLE-11, IOS-ENT-04
4. **Category minimums missed** — UGC (terms + filter + report + block + contact), subscriptions (name/period/price + EULA & privacy links **in app and in metadata**), account deletion in-app + web. → UGC-*, PAY-02, ACC-02
5. **Sign-in asymmetry** — social login without Sign in with Apple; asking name/email again after SIWA; rejecting relay emails; wrong button wording. → IOS-LOGIN-01, IOS-LOGIN-04
6. **Purpose strings and disclosures in the wrong place or too vague** — "what" without "why + example"; the post-deny message; not localized; Play disclosures in the listing instead of in-app. → PERM-01, IOS-PLIST-01, PRIV-04
7. **Declared capability with no visible feature** — background audio for timers/alarms/recording; FGS type declared but not started; Data safety missing SDK collection. → IOS-BG-01, AND-PERM-05, PRIV-02
8. **Store listing must explain sensitive features** — Health Connect, FGS, VPN, background location, financial declarations are judged from the **full description** and demo **video**. → AND-CONSOLE-06, AND-CONSOLE-09
9. **Hosting defects** — privacy policy / deletion URL on GitHub Markdown, Blogspot, PDF, editable posts, JS-only pages, servers that fail non-browser TLS. → PRIV-01, ACC-02
10. **Automated heuristics** — 4.3 similarity/terminated-account matches, "free"/"libre", "Tutorial & Rules", WakeLock as "changing device settings", threat-feed false positives. What worked: substantial icon/UI/feature change, evidence-heavy appeals, reviewer notes on every later update. → CONTENT-07, META-02, AND-QUALITY-02
