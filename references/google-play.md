# Google Play — Developer Program Policies & Play Console requirements

Verified 2026-08-28. Policy Center: https://support.google.com/googleplay/android-developer/topic/9858052 . Quotes are verbatim from the linked pages.

## Content & user data

| Policy | Key requirements (verbatim) | URL |
|---|---|---|
| **User Generated Content** | Apps with UGC must: "Requires users accept the app's terms of use and/or user policy before users can create or upload UGC" · "Defines objectionable content and behaviors… and prohibits them" · "Conducts UGC moderation, as is reasonable and consistent with the type of UGC" · "Provides an in-app system for reporting and blocking objectionable UGC and users, and taking action against UGC or users where appropriate" · "Provides safeguards to prevent in-app monetization from encouraging objectionable user behavior". Incidental sexual UGC "hidden by default behind filters that require at least two user actions"; "Apps whose primary purpose is featuring objectionable UGC will be removed"; violation: "continually failing to address user complaints" | https://support.google.com/googleplay/android-developer/answer/9876937 · https://support.google.com/googleplay/android-developer/answer/12923286 |
| **Child Safety Standards** | Social & Dating (since 2025-01-22) and anonymous/random chat (since 2026-07-15): "Have published standards against child sexual abuse and exploitation (CSAE)", "Provide an in-app mechanism for user feedback", address CSAM, comply with child-safety laws, "Provide a child safety point of contact"; self-certify in Play Console | https://support.google.com/googleplay/android-developer/answer/14747720 · https://support.google.com/googleplay/android-developer/answer/15444680 |
| **Age-Restricted Content** | dating, random/anonymous chat, real-money gambling "are required to use the Play Console functionality and tools to block minors" (2025-10-30) | https://support.google.com/googleplay/android-developer/answer/16302250 |
| **AI-Generated Content** | "must contain in-app user reporting or flagging features that allow users to report or flag offensive content… without needing to exit the app" | https://support.google.com/googleplay/android-developer/answer/13985936 |
| **User Data** | Privacy policy linked in Play Console **and** in the app; must include developer info/contact, data types accessed/collected/used/shared, "Secure data handling procedures", retention/deletion, be labeled as a privacy policy, name the listing entity. **Prominent disclosure & consent**: "Must be within the app itself… displayed in the normal usage of the app and not require the user to navigate into a menu… Must describe the data being accessed or collected… Must explain how the data will be used and/or shared"; consent "Must require affirmative user action"; "Must not use auto-dismissing or expiring messages". Format: **"[This app] collects/transmits/syncs/stores [type of data] to enable ['feature'], [scenario]."** Data safety: "'Collect' means transmitting data from your app off a user's device" incl. SDKs; "advertising identifier" under Device or other IDs; discrepancies → enforcement. Applies to third-party AI integrations (2026-07) | https://support.google.com/googleplay/android-developer/answer/10144311 · https://support.google.com/googleplay/android-developer/answer/10787469 |
| **Account deletion** | "If your app allows users to create an account from within your app… it must also allow users to request for their account to be deleted" — in-app path **and** "a web link resource where users can request app account deletion" in Data safety; "Temporary account deactivation, disabling, or 'freezing'… does not qualify"; enforced 2024-05-31 | https://support.google.com/googleplay/android-developer/answer/13327111 |

| Full-screen intent | "Only apps whose core functionality is a high-priority use case of setting an alarm or receiving phone or video calls will be automatically granted"; others must request and "gracefully degrade"; FSI abuse for ads banned | declaration 2024-05-31; default-off 2025-01-22 | https://support.google.com/googleplay/android-developer/answer/13392821 · https://support.google.com/googleplay/android-developer/answer/13315670 |

| VpnService | core VPN + parental control/enterprise, usage tracking, security, network tools, browsers, carriers; never "Redirect or manipulate user traffic… for monetization" | — | https://support.google.com/googleplay/android-developer/answer/12564964 |
| Android Studio lint | "Google Play policy insights" flag AAID, accessibility, all files, location, photo/video, SMS, VPN, exact alarm, FSI, Health Connect, package visibility, install packages | — | https://support.google.com/googleplay/android-developer/answer/16297427 |

## Ads, Families, metadata, functionality

| Policy | Key requirements | URL |
|---|---|---|
| **Ads** | "The Android advertising identifier (AAID) must only be used for advertising and user analytics"; "Full screen interstitial ads of all formats… that show unexpectedly… are not allowed"; not at level start / content-segment start; "not closeable after 15 seconds are not allowed"; rewarded ads exempt; "Ads must not simulate or impersonate the user interface"; lockscreen monetization banned | https://support.google.com/googleplay/android-developer/answer/9857753 |
| **Advertising ID** | targetSdk 33+ must declare `com.google.android.gms.permission.AD_ID`; deleted ID returns zeros | https://support.google.com/googleplay/android-developer/answer/6048248 |
| **Contains ads** declaration | "You must declare whether or not your app contains ads" (incl. SDK ads); prerequisite for Target audience | https://support.google.com/googleplay/android-developer/answer/9859455 |
| **Families** | children in target audience → "Only use Google Play Families Self-Certified Ads SDKs" (program "currently not accepting new applicants"), no interest-based ads, no AAID/IMEI transmission for child-only apps, AR safety warning, social apps "an in-app reminder to be safe online"; mixed audience → neutral age screen; unintended appeal → rejection; "Teacher Approved" opt-in | https://support.google.com/googleplay/android-developer/answer/9893335 · https://support.google.com/googleplay/android-developer/answer/9867159 · https://support.google.com/googleplay/android-developer/answer/9283445 |
| **Metadata** | title "30 characters or less"; no "emojis, emoticons, or repeated special characters"; no store-performance/rank/price/promo text in title, icon or developer name ("App of the year", "#1", "Best of Play", "10% off", "free for limited time only", "Editor's choice", "New"); no all caps; no "unattributed or anonymous user testimonials" | https://support.google.com/googleplay/android-developer/answer/9898842 |
| **Store listing assets** | icon 512×512 32-bit PNG ≤ 1024 KB; feature graphic 1024×500; screenshots ≥ 2, 320–3840 px (featuring: ≥ 4 at ≥ 1080 px); video = public/unlisted YouTube, ads disabled | https://support.google.com/googleplay/android-developer/answer/9866151 |
| **Deceptive Behavior / Impersonation** | no "false or misleading information or claims, including in the description, title, icon, and screenshots"; no "hidden, dormant, or undocumented features"; no impersonating developers/entities/apps | https://support.google.com/googleplay/android-developer/answer/9888077 · https://support.google.com/googleplay/android-developer/answer/9888374 |
| **Functionality, Content, and User Experience** | "We do not allow apps that only have limited functionality and content"; "We don't allow apps that crash, force close, freeze, or otherwise function abnormally" | https://support.google.com/googleplay/android-developer/answer/9898783 |
| **Content Ratings (IARC)** | "All apps must have a content rating… Apps without a content rating will be removed"; "Misrepresentation of your app's content may result in removal or suspension"; "Users Interact" = user-to-user communication/media sharing | https://support.google.com/googleplay/android-developer/answer/9898843 · https://support.google.com/googleplay/android-developer/answer/9859655 |

## Payments

| Topic | Key requirements | URL |
|---|---|---|
| **Payments** | Play billing for "in-app features or services, including any app functionality, digital content or goods"; exempt: physical goods/services, P2P, donations; no steering via listing, promotions, webviews, buttons, links, ads | https://support.google.com/googleplay/android-developer/answer/9858738 |
| **Subscriptions** | disclose "the cost of your subscription, the frequency of your billing cycle, the automatic renewal terms"; trial "duration, pricing… how it converts, how to cancel"; "easy-to-use, online method to cancel" in account settings (clarified 2025-10-30) | https://support.google.com/googleplay/android-developer/answer/9900533 |
| **Korea** | Play billing alongside; "service fee will be reduced by 4%" for alternative billing; APIs mandatory since 2023-08-02; report within 24 h | https://support.google.com/googleplay/android-developer/answer/11222040 |
| **EEA** | alternative billing / External offers program | https://support.google.com/googleplay/android-developer/answer/12348241 · https://support.google.com/googleplay/android-developer/answer/14372887 |
| **US** | external content links + alternative billing programs (launched 2025-12-09; comply by 2026-01-28; fees from 2026-10-01) | https://support.google.com/googleplay/android-developer/answer/15582165 · https://support.google.com/googleplay/android-developer/answer/16671517 |
| **Japan** | external payments program; "Play store listings must not mention out-of-app purchases" | https://support.google.com/googleplay/android-developer/answer/16787536 |
| **Global fee model** | from 2026-06-30 (EEA/UK/US): 5% billing fee for Play Billing, 20% IAP, 10% subscriptions; AU 2026-09-30; KR/JP 2026-12-31; rest 2027-09-30 | https://android-developers.googleblog.com/2026/03/a-new-era-for-choice-and-openness.html |

## Platform & account requirements

| Topic | Requirement | URL |
|---|---|---|
| **Target API level** | "New apps and app updates must target Android 16 (API level 36) or higher" by **2026-08-31** (Wear/Automotive 15); "Existing apps must target Android 15 (API level 35) or higher to remain available to new users"; extension to 2026-11-01 | https://support.google.com/googleplay/android-developer/answer/11926878 |
| **16 KB page size** | "Starting November 1st, 2025, all new apps and updates… targeting Android 15+ devices must support 16 KB page sizes"; "Starting February 1, 2027, if your app updates don't support 16 KB… you won't be able to release these updates" | https://android-developers.googleblog.com/2025/05/prepare-play-apps-for-devices-with-16kb-page-size.html · https://developer.android.com/guide/practices/page-sizes |
| **Technical quality** | crash ≤ 1.09%, ANR ≤ 0.47%; native code 64-bit + 16 KB; 25% code optimization from 2027-02; Zero-Tap Sign-In 2027-04 | https://support.google.com/googleplay/android-developer/answer/17492799 |
| **App Bundle / signing** | AAB required for new apps since 2021-08; Play App Signing; upload key "Must be an RSA key of 2048 bits or more" | https://developer.android.com/guide/app-bundle · https://support.google.com/googleplay/android-developer/answer/9842756 |
| **Closed testing (new personal accounts)** | "personal accounts created after November 13, 2023, must run a closed test… with a minimum of 12 testers who have been opted in continuously for at least 14 days"; "If a tester opts out and opts back in later, the 14 days must be consecutive" | https://support.google.com/googleplay/android-developer/answer/14151465 |
| **Account verification** | identity document must match the payments profile; organizations need D-U-N-S; developer details shown publicly | https://support.google.com/googleplay/android-developer/answer/13628312 · https://support.google.com/googleplay/android-developer/answer/10841920 |
| **App registration (2026)** | register apps in Play Console by **2026-09-30** or "global removal from Google Play"; financial/health/VPN/government apps "must register as an Organization" | https://support.google.com/googleplay/android-developer/answer/17125096 |
| **Sign-in details** (App access) | "must be accessible at all times, reusable, and valid regardless of user location"; "provide reusable login credentials that can bypass" 2-Step/OTP; "must be provided in English"; expired password → rejection | https://support.google.com/googleplay/android-developer/answer/15748846 · https://support.google.com/googleplay/android-developer/answer/9859455 |
| **Mandatory declarations** | Health apps declaration for **all** apps (after 2024-08-31); Financial features declaration for all apps (updates blocked since 2025-10-30 until completed); News; Government; Blockchain via Financial | https://support.google.com/googleplay/android-developer/answer/14738291 · https://support.google.com/googleplay/android-developer/answer/13849271 · https://support.google.com/googleplay/android-developer/answer/9935326 · https://support.google.com/googleplay/android-developer/answer/9514050 |
| **Publishing tips** | "make sure to provide an active demo account"; "Multiple rejections may lead to app suspension" | https://support.google.com/googleplay/android-developer/answer/15191715 |
| **Enforcement** | rejection / removal / suspension / limited visibility / termination; "Suspensions count as strikes" | https://support.google.com/googleplay/android-developer/answer/9899234 |
